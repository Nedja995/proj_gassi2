## Core Production Chains

### Brick Production (always running)
Clay pit → clay → Kiln → bricks → construction

Kilns are the production bottleneck for all construction. Run as many kilns
as clay supply allows. Never let kilns idle when you have building queued.

### Food Chain — Grain Cycle
Grain farm → grain → Granary → Bakery → bread → Granary → Bazaar

Grain is seasonal. Farm during the growth season; ensure granaries have
enough grain stored to run bakeries through the off-season.

### Food Chain — Date Cycle
Date palm farm → dates → Granary → Bazaar

Dates are year-round and low-complexity. Build date farms early as the
second food type for housing evolution.

### Goods Chain — Pottery
Clay pit → clay → Pottery Workshop → pottery → Storehouse → Bazaar

Pottery is the first goods type required for tier 3 housing. Establish
pottery production alongside the first grain loop.

### Goods Chain — Linen
Flax farm → flax → Weaving Workshop → linen cloth → Storehouse → Bazaar

Linen is required for tier 4 housing. Flax farms require fertile land
near the river. Establish linen before attempting large villa evolution.

### Goods Chain — Beer
Grain → Brewery → beer → Storehouse → Bazaar

Beer competes with bakeries for grain supply. Run enough grain farms to
supply both. Beer is required for mid-tier housing and entertainment venues.

## Labor Requirements per Building (approximate)

- Grain/date farm: 4-6 workers
- Kiln: 3-4 workers
- Pottery/bakery/brewery: 3-4 workers
- Bazaar: 4-6 workers (more walkers = better coverage)
- Granary/storehouse: 2-3 workers
- Temple: 4-6 workers

Total labor for a stable early city (500 pop): approximately 80-120 workers.
A city of 500 shacks provides far fewer workers than 500 evolved houses.
Prioritise housing evolution to increase worker output per tile.
